NOITE DO TERROR

Noite do terror é uma landing page criada para apresentar e indicar filme de terror de diferentes estilos.

O site foi criado com uma estética sombria ,feita principalmente com as cores preto ,vermelho e branco ,buscando trazer uma atmosfera mais aterrorizante.

O projeto apresenta filmes divididos em três categaroias:
terror slasher
terror sobrenatural
terror psicològico
Além disso, o site possui uma galeria com cenas de clássicos do cinema do terror e uma área de contato para indicações de novos filmes.
